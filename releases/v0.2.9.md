# v0.2.9

> Released: 2026-07-19

## Highlights

- **Faster, smoother canvas navigation** - Panning the canvas now takes a fast path that only updates the three board CSS variables instead of running the full render pipeline. `syncMountedCanvasNodes` short-circuits when the active canvas has not changed, so non-structural renders no longer walk every node of every canvas. Canvas navigation stays smooth with many terminals.
- **Event-driven agent synchronization** - The fixed 6-second polling loop is gone. The main process now watches the agentmux SQLite database for mtime changes and emits `canvas-agent:changed` to subscribed renderers, so new child agents appear within ~250ms instead of waiting for the next poll. A 30s liveness poll remains as a fallback.
- **Event-driven terminal tail lines** - The one-line status under each terminal now refreshes on data events via a coalesced rAF, not a global 4s `setInterval` that walked every active-canvas terminal's buffer. Idle CPU drops significantly with many terminals.
- **Multi-select mode for closing terminals** - A new "Select terminals" action in the canvas actions menu lets you click terminals to add them to a selection (red outline), then press `Escape`/`Delete`/`Backspace` or click "Close selected" to destroy them in bulk. Useful for cleaning up stale or duplicate terminals.

## Improvements

- New `main_agent_graph_watcher.js` watches the agentmux DB via `fs.watch` + mtime-poll fallback (unref'd timers) and notifies subscribed renderers.
- New IPC: `canvas-agent:subscribe` / `canvas-agent:unsubscribe`; preload exposes `subscribeCanvasAgentChanges`, `unsubscribeCanvasAgentChanges`, `onCanvasAgentChanged`.
- Renderer subscribes on init, resubscribes when the active canvas's project tag changes, debounces events (250ms), and keeps a 30s liveness poll as fallback.
- Pan-only viewport frames skip `renderCanvasOverviewHeader`, `renderCanvasNotes`, `applyCanvasFocusMode`, `updateEmptyState`, `scheduleMinimapRender`, and per-node positioning work.
- `renderedCanvasId` invariant: `syncMountedCanvasNodes` returns immediately when the active canvas has not changed since the last mount pass.
- Terminal tail updates coalesce into a single rAF with a `pendingTailUpdateNodes` set; the 4s global `setInterval` is replaced by a 30s liveness pass.
- New `.board-select-mode-bar` status bar with count, "Close selected", and "Cancel (Esc)" actions.
- Select mode auto-exits on canvas switch and cleans up when a selected node is destroyed.

## Fixes

- Fixed canvas lag caused by O(total nodes across all canvases) work firing on every pointermove frame.
- Fixed idle CPU churn caused by the 4s global terminal-tail refresh walking every active-canvas terminal's buffer.
- Fixed agent graph updates taking up to 6 seconds to surface when polling was the only synchronization path.
