# v0.2.8

> Released: 2026-07-19

## Highlights

- **Terminal startup is now asynchronous and bounded** - Creating many terminals at once no longer blocks the main process. A bounded async pool brings up PTY/tmux sessions concurrently, keeps the renderer responsive while nodes initialize, and falls back to the stable DOM renderer beyond a WebGL budget so large canvases stay smooth.
- **Terminal session identity is duplicate-safe** - Session keys are now generated and validated through a dedicated registry, so relaunching a canvas that references a still-running tmux session reattaches to the right shell instead of racing a duplicate. Closing a node permanently destroys the underlying session, while closing the window still detaches live tmux-backed sessions for reattach.
- **Canvas hierarchy and delegation graph** - Canvases now track an agent-project tag and a delegation edge graph derived from the agentmux peer state, with automatic horizontal placement for new agent nodes. Switching canvases re-syncs the agent graph and renders edges on the active board.
- **macOS permissions and Full Disk Access** - New entitlements and a README section explain how to install TermCanvas in `/Applications` and grant Full Disk Access for unrestricted developer workflows. The app remains unsigned and works without a paid Apple Developer account.

## Improvements

- Tmux-backed terminal lifecycle has been extracted into `main_tmux_backend.js` for clearer separation from the main session registry.
- Terminal registry logic lives in `main_terminal_registry.js`, with duplicate-safe session keys and explicit owner/pty/backend tracking.
- Renderer-side canvas delegation is centralized in `renderer_canvas_delegation.js`, including edge rendering and placement for agent canvases.
- Async terminal pool (`renderer_async_pool.js`) bounds concurrent terminal bring-up and surfaces ready/failed state to the renderer.
- Session snapshots now persist canvas agent-project tags and delegation edges alongside existing node layout state.
- WebGL addon lifecycle pauses hidden terminals and falls back to the DOM renderer past the configured budget, reducing GPU pressure on large canvases.
- Agentmux child sync and terminal scaling fixes keep peer agent state consistent across canvas switches and resizing.

## Fixes

- Fixed agentmux child sync drift that could desync peer state after rapid canvas switches.
- Fixed terminal scaling regressions that produced incorrect row/column counts after maximize/restore.
- Fixed duplicate session keys that previously caused relaunch to attach to the wrong tmux session.
- Fixed terminal header title updates so cwd and shell name stay accurate after reconnect.
