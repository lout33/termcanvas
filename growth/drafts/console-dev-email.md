**Subject:** Tool submission: TermCanvas — spatial terminal canvas for steering multiple AI agents

Hi,

I'd like to submit TermCanvas for consideration in Console.

TermCanvas is an open-source (MIT) macOS desktop app that puts real tmux-backed terminal sessions as draggable nodes on an infinite canvas. It's built for developers running and steering multiple AI coding agents at once — commander→worker delegation lines are drawn between the agent terminals so you can see the swarm topology and spot which agent is blocked or needs you.

- Repo: https://github.com/lout33/termcanvas
- Demo video: https://www.youtube.com/watch?v=4XN5jvk9P1U
- Stack: Electron, node-pty, tmux, xterm.js
- Platform: macOS (Apple Silicon)
- License: MIT

Happy to answer any questions.
