## Description (≤260 chars — this one is ~250)
```
TermCanvas is an open-source, tmux-backed desktop app that puts your terminals
and AI coding agents as nodes on an infinite canvas — with commander→worker
delegation lines so you can steer the whole fleet. macOS (Apple Silicon), early.
```

## Maker's first comment
```
Maker here. I run several AI agents plus shells and kept losing the thread across
tabs, so I built a canvas that shows each as a node and draws the commander→worker
delegation between them. It's open source and tmux-backed — sessions are durable
and reattach from a plain terminal, which sets it apart from the closed/native
agent-canvas tools (Maestri, Agent Grid).

Honest: macOS Apple Silicon only, v0.2.5, solo dev. I'd love feedback on whether a
spatial delegation map actually beats a tab list for steering many agents.

Repo: https://github.com/lout33/termcanvas
```
